# Independent review: statistics, temporal leakage, unsupported claims

Reviewer: independent statistics reviewer (did not write the code). Worktree `pc-review-stats`, detached at
`28f5e602` (`feat/physiology-context-20261005`). Scope: spec-19 §6, §8, §12, §14, V03, V10–V13, C03, C05, C11, C12.
No production code was changed. Every scratch test asserts the behaviour the spec asks for, so a **failure is the
demonstration**. The tests are in `Packages/StrandAnalytics/Tests/StrandAnalyticsTests/ReviewStatsTests.swift`
(not committed).

## Verdict summary

- **Leakage inside System F holds.** No comparison, episode or frozen selection for day D reads a value from day D or
  later. The worker's causal history queries filter by mode, by `day ∈ [D−90, D−1]` and by publication time ≤ cutoff.
- **The arithmetic reproduces.** The robust-statistics arithmetic (MAD, small-sample factor, ln scale, centre SE)
  matches my independent checks. The evaluation tables reproduce within sampling error with two new seeds.
- **The evaluated detector is not the one documents run** (R-F2): the worker loads only 90 days of history.
  Episode lists therefore carry about 2× as many false persistent episodes at φ = 0.3, and about 4× at φ = 0.5.
- **Scale floors fail for count-like series** (R-F1): zero-centred functional series get a 1e-6 floor.
- **Dependence mapping misses two links** (V13: R-F3, R-F4).
- **Target-dependent nightly selection is declared but not evaluated** (P1).
